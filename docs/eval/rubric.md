# rfp-analyzer eval — 루브릭 (실행 전 고정)

- 대상 스킬: `proposal-workbench:rfp-analyzer`
- 입력: 코레일 XAIS 사업 RFP (`RFP 원문/2제안요청서.md` 153p, `1입찰공고문.md` 12p, `3용역설계서.md` 62p)
- 고정 시각: 2026-09-22 (스킬 실행 **전**)
- 사이클: 1회차 (baseline)

## 채점 항목

| # | 항목 | 배점 | 측정 방법 |
| --- | --- | --- | --- |
| R1 | 요구사항 recall | 40 | 정답지 49개 ID 중 출력에 포함된 개수 ÷ 49 × 40 |
| R2 | 분류 정확도 | 15 | 잡아낸 요구사항을 올바른 도메인(기능/데이터/인터페이스/보안/품질/테스트/PM/제약/장비)에 배치했는가 |
| R3 | 정량 KPI 추출 | 15 | 아래 KPI 정답지 대비 추출 비율 |
| R4 | 숨은 기능·의무 | 15 | 요구사항 표에 ID로 없지만 본문에 있는 의무사항 포착 (아래 목록) |
| R5 | 환각 없음 | -30 ~ 0 | RFP에 없는 내용을 사실처럼 서술하면 건당 -10 (상한 -30) |
| R6 | 산출물 사용성 | 15 | 제안서 목차로 바로 이어붙일 수 있는 형태인가, 근거 위치를 되짚을 수 있는가 |

합계 100점 (R5는 감점). **60점 미만이면 실무 투입 불가**로 판정한다.

## 정답지 C — 숨은 의무 (요구사항 ID 없음)

- 요구항목이 제안서 어디에 기술됐는지 **참조표(추적표) 제시 의무**
- 모호 표현("할 수 있다", "고려하고 있다")은 **평가 시 불가능으로 간주**
- 블라인드: 부본 컬러·색지 금지, 회사명·로고·대표자명·사업자번호 금지, 인물사진 전면 금지
- 편집 서식 강제: 신명조, 15/14/13pt, 여백 25-15-20-20, 쪽번호 `-1-`
- 제출물 5종 분리 (계량 원본 / 비계량 원본·부본 / 요약문 원본·부본), PDF only, DRM·압축 불가
- 퇴직자 임·직원 고용확인서 [별지 11호] 별도 제출 — 미제출 시 입찰 무효
- 안전보건수준평가 → 기술제안서 **Ⅵ. 안전보건** 부문 작성
- 참가자격: 중소기업·소상공인 한정 (중견·대기업, 상호출자제한기업집단 배제)
- 영문약어표 제공, 미터법·원화 사용

## 기록할 것

- 실행 소요 시간, 출력 분량
- R1 미검출 ID 목록 (= 실패 케이스, 다음 사이클 개선 타깃)
- R5 환각 사례 원문 인용
