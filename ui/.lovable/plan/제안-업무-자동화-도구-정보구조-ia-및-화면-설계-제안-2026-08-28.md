# 제안 업무 자동화 도구 — 정보구조(IA) 및 화면 설계 제안

백엔드 없이 mock 데이터만으로 화면 구조와 사용 흐름을 먼저 설계합니다.

## 1. 전체 구조

7개 기능을 각각 독립 실행 가능한 "도구(Tool)"로 두고, 왼쪽 고정 사이드바로 언제든 이동합니다. 정해진 순서를 강제하는 마법사(wizard)는 만들지 않습니다.

```text
┌─────────────┬────────────────────────────────────┐
│  사이드바    │  상단 바 (도구명 / 상태 / 액션)      │
│  · 홈       ├────────────────────────────────────┤
│  · 문서 변환 │                                    │
│  · RFP 분석 │   도구 작업 영역                     │
│  · PPT 등록 │   (좌: 입력·목록 / 우: 결과·상세)     │
│  · 제안서 검색│                                   │
│  · 장표 기획 │                                    │
│  · PPT 생성 │                                    │
│  · PPT 검수 │                                    │
└─────────────┴────────────────────────────────────┘
```

라우팅
- `/` 홈(도구 허브)
- `/convert`, `/rfp`, `/ingest`, `/search`, `/planning`, `/generate`, `/review`

각 도구 화면은 "입력 패널 + 결과 패널" 2단 레이아웃으로 통일해 학습 비용을 줄입니다. 도구 간 이동은 선택적 연결(예: 변환 결과를 RFP 분석으로 보내기)로만 제공하고, 강제하지 않습니다.

## 2. 화면별 구성과 필요한 데이터

### 홈 (도구 허브)
- 7개 도구 카드: 이름, 한 줄 설명, 최근 실행 시각, 처리 건수
- 최근 작업 목록 표(도구명, 대상 파일, 상태, 시각)
- 데이터: `tools[]`(id, name, desc, lastRunAt, count), `recentJobs[]`(id, tool, target, status, updatedAt)

### 1) 문서 변환 `/convert`
- 좌: 업로드 영역(HWP/HWPX/PDF/DOCX), 파일 목록 + 변환 상태
- 우: Markdown / 구조화 텍스트 탭 미리보기, 다운로드 버튼(.md/.txt)
- 데이터: `documents[]`(id, fileName, fileType, size, status, progress, pageCount, convertedAt), `conversionResult`(markdown, sections[]{heading, level, text, page})

### 2) RFP 분석 `/rfp`
- 좌: 입력 선택(파일 업로드 또는 변환 결과 선택)
- 우: 섹션 탭 — 사업 개요 / 목표 업무 흐름 / 요구사항 / 기능 도메인 / 명시 기능 / 숨은·보완 기능 / 정량 요구사항·KPI / 난이도 높은 영역
- 각 항목 클릭 시 우측 슬라이드 패널에 원문 근거(문서명, 페이지, 인용문) 표시
- 데이터: `rfpAnalysis`(overview, workflowSteps[], requirements[]{id, category, text, priority, sourceRefs[]}, domains[], explicitFeatures[], hiddenFeatures[]{text, reason}, kpis[]{metric, target, unit, sourceRefs[]}, riskAreas[]{area, reason, level}), `sourceRefs[]`(docName, page, quote)

### 3) 기존 PPT 등록 `/ingest`
- 좌: PPTX 업로드, 등록 작업 목록(파일별 진행률)
- 우: 슬라이드별 분석 테이블/그리드 — 썸네일, slide number, 제목, 설명, 태그, 분석 상태
- 하단: 검색 DB 등록 결과 요약(성공/실패/스킵 수)
- 데이터: `ingestJobs[]`(id, fileName, totalSlides, doneSlides, status), `slides[]`(id, deckId, slideNumber, thumbnailUrl, title, description, tags[], status), `indexResult`(indexed, failed, skipped)

### 4) 기존 제안서 검색 `/search`
- 상단: 자연어 검색창 + 필터(연도, 사업 유형, 태그)
- 결과: 슬라이드 카드 그리드(썸네일, 제목, 원본 PPT명, slide number, 설명, 태그, similarity 점수)
- 카드 클릭 → 큰 미리보기 모달(좌우 이동, 메타 정보, "장표 기획에 참고자료로 추가")
- 데이터: `searchResults[]`(slideId, thumbnailUrl, title, deckName, slideNumber, description, tags[], similarity)

### 5) 제안 장표 기획 `/planning`
- 좌: 입력(RFP 요구사항 선택 또는 직접 설명 입력) + 기획된 장표 목록
- 우: 선택 장표의 기획서 편집 화면 — 제목, governing message, 핵심 블록(추가/삭제/순서 변경), 사용할 정량지표, source reference, 참고 장표 썸네일
- 하단 액션: 저장 / 승인(승인 시 상태 뱃지 변경, PPT 생성으로 전달 가능)
- 데이터: `slidePlans[]`(id, title, governingMessage, blocks[]{id, type, text}, metrics[]{label, value, unit, sourceRef}, sourceRefs[], referenceSlides[], status: draft|approved)

### 6) PPT 생성 `/generate`
- 좌: 승인된 장표 기획 선택(체크박스 목록), 템플릿 선택
- 우: 생성 진행 상태 → 생성된 슬라이드 미리보기 그리드 → PPTX 다운로드 영역
- 데이터: `generationJob`(id, status, progress, createdAt), `generatedSlides[]`(slideNumber, title, thumbnailUrl, planId), `outputFile`(fileName, size, downloadUrl)

### 7) PPT 검수 `/review`
- 좌: 입력(기존 PPTX 업로드 또는 생성 결과 선택), 이슈 유형별 필터
- 우: 이슈 목록 — 요구사항 누락 / 정량 수치 변경 / 근거 없는 표현 / 레이아웃 문제, 각 이슈에 심각도, 해당 슬라이드 번호, 설명, 근거, 권장 조치
- 이슈 클릭 시 해당 슬라이드 미리보기 함께 표시
- 데이터: `reviewResult`(score, summary{critical, warning, info}), `issues[]`(id, type, severity, slideNumber, message, evidence, suggestion)

## 3. 디자인 방향
- 내부 업무도구 톤: 중성 회색 기반, 좁은 여백, 명확한 상태 뱃지와 표 중심 UI
- 거대한 히어로, 과한 그라데이션·글래스 효과 없음, 데스크톱 우선
- shadcn/ui 기반 컴포넌트(테이블, 탭, 시트, 다이얼로그, 뱃지, 프로그레스) 적극 사용
- 전 화면 공통: 빈 상태, 로딩(스켈레톤), 완료 상태를 mock으로 모두 표현

## 4. 기술 사항
- 프론트엔드 전용. 외부 API·DB·인증 없음
- mock 데이터는 `src/mocks/*.ts`에 도구별 파일로 분리하고 타입은 `src/types.ts`에 정의
- 슬라이드 썸네일 등 이미지는 자리표시용 정적 에셋으로 생성
- 도구 간 데이터 전달(변환→분석, 검색→기획, 기획→생성)은 클라이언트 상태로만 처리하며 선택적

## 5. 승인 후 진행 순서
1. 디자인 시스템 + 앱 셸(사이드바/상단바) + 홈 허브
2. 문서 변환, RFP 분석
3. PPT 등록, 제안서 검색
4. 장표 기획, PPT 생성, PPT 검수
