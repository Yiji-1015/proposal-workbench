# Unified Proposal Pattern Library

도식 구조를 우선으로 검색하는 통합 라이브러리입니다. 내용 태그는 보조 정보이며, visual tags가 우선입니다.

`aspect_ratio`는 원본 모듈의 기하 비율이며 슬라이드 방향 제한이 아닙니다. 모든 모듈은 기본적으로 가로형과 세로형에서 fit, relabel, crop, reflow, split, rotate 방식으로 재사용할 수 있습니다.
